# De Jager Attorneys: website concept

Concept website for De Jager Attorneys Inc. (Strubens Valley, Roodepoort), designed by Pablo Lebelo (mrpoint.online).

Single static page (`index.html`) with hash-routed pages and dropdown menus. Deploys as static assets on Cloudflare Workers/Pages with no build step.

Not the official website of De Jager Attorneys. Marked `noindex`.
